PsyStat 검토 안내문 (내부망 보안·오픈소스 검토용)
====================================================

작성일: 2026-11-20 / 버전: 0.6.1
작성: 사용자 요청으로 AI 코딩 도우미(Claude)가 작성. 아래 사실관계는 코드 검색 결과에 근거함.


1. 무엇인가
-----------
- 심리학 연구용 통계 프로그램. 웹 브라우저(Chrome/Edge)에서 여는 HTML 파일 1개로 동작한다.
- 설치, 관리자 권한, 인터넷 연결이 필요 없다. 별도 실행 파일(.exe 등)이 없다.
- 분석: 기술통계, t검정, 분산분석, 상관(다분상관 포함), 교차분석, 선형·로지스틱·위계적 회귀,
  조절·매개(PROCESS 방식), MANOVA, 판별분석, 신뢰도, 네트워크 분석, 구조방정식(CFA/SEM).


2. 파일 구성
-----------
  PsyStat.html.txt          실제 사용할 파일(단일 파일판, 298,346바이트). 확장자만 .txt로 바꾼 것으로 내용은 바이트 단위로 동일.
                            (검토·승인 후 이름을 PsyStat.html로 바꾸면 그대로 실행됨)
  split/PsyStat.html.txt + split/PsyStat-engine.js.txt
                            분할판(두 파일을 같은 폴더에 두고 사용). 기능·코드 동일.
  src/stats/stats-1.js.txt  통계 계산 엔진 조각 1: 특수함수·분포·행렬·기초통계·검정·회귀·신뢰도 (863줄)
  src/stats/stats-2.js.txt  통계 계산 엔진 조각 2: 네트워크·다분상관·조절·매개·다변량 (951줄)
  src/sem.js.txt            구조방정식 엔진 (506줄)
  src/app/app-1~4.js.txt    화면(UI) 코드 조각 1~4 (합계 1,628줄)
  src/style.css.txt         화면 서식
  src/index.template.html.txt  HTML 틀
  src/stats.js.txt          Node.js 검증용 로더(조각을 불러오기만 함; 브라우저에서는 쓰지 않음)
  src/build.js.txt          위 파일들을 하나의 HTML로 합치는 스크립트 (Node.js용; 내부망 실행 불필요)
  SHA256SUMS.txt            각 파일의 SHA-256 해시

  PsyStat.html.txt = index.template.html 안에 style.css와 각 조각(.js)을 각각 별도의 <script> 블록으로 끼워 넣은 것이다.
  코드는 압축·난독화하지 않았다.

  [조각으로 나눈 이유 — 0.6.0 변경]
  메일로 전달된 0.5.0 파일(286KB)이 도착 시 83KB로 손상되어 있었다(계산 엔진 블록의 앞뒤가 사라짐).
  0.2.0 파일(가장 큰 스크립트 블록 약 95KB)은 정상 도착했으므로, 큰 스크립트 블록이 전송 과정에서 손상된다고 보고
  모든 블록을 60KB 이하로 나눴다(현재 가장 큰 블록 약 56KB, 빌드 시 자동 검사). 조각들은 공유 객체
  (__PsyStatsNS, __PsyAppNS)를 통해 함수를 주고받으며, 계산 코드는 분할 전과 줄 단위로 동일함을 비교 확인했다
  (의도한 변경 3줄: 내보내기 객체 이름, 자료 상태 갱신 방식, 변수 선언 위치).
  [0.6.1 추가] 블록 분할만으로는 해결되지 않아, 파일 맨 앞에 '자가 점검' 스크립트를 넣었다. 각 블록의 길이와
  2,000자 단위 지문(FNV-1a 해시)을 비교해 어느 블록의 어느 구간이 원본과 다른지 화면에 표시한다(외부 통신 없음,
  파일 안의 코드만 읽음). 원본과 같으면 아무것도 표시하지 않는다.
  ※ 이 원인 판단은 도착 파일 분석에 근거한 추정이며, 메일 시스템의 실제 처리 규칙은 메일·보안 담당자 확인이 필요하다.

3. 보안 관련 사실 (코드 전체 문자열 검색 결과)
---------------------------------------------
  [사용하지 않음: 검색 결과 0건]
  fetch, XMLHttpRequest, WebSocket, EventSource, navigator.sendBeacon, postMessage,
  eval, new Function, Worker, importScripts, document.cookie, indexedDB, sessionStorage,
  window.open, <iframe>, <img>(외부 이미지)

  [외부 통신 원천 차단]
  HTML 머리에 다음 Content-Security-Policy가 있다. 브라우저가 이 파일의 모든 네트워크 요청을 차단한다.
    default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline';
    img-src data: blob:; connect-src 'none'; form-action 'none'
  ('unsafe-inline'은 스크립트가 파일 내부에 있기 때문에 필요하다. 외부 스크립트는 불러올 수 없다.)
  분할판만 script-src에 'self'를 추가했다: 같은 PC의 로컬 파일(PsyStat-engine.js)을 <script src>로 읽기 위함이며,
  connect-src 'none'은 그대로이므로 네트워크 통신은 여전히 차단된다. 분할판 HTML이 불러오는 외부 파일은
  PsyStat-engine.js 하나뿐이다(코드 검색으로 확인 가능: '<script src=' 1건).

  [파일에 들어 있는 URL 문자열 36개: 모두 요청을 일으키지 않음]
  - 참고문헌 DOI 등 28개: 화면에 글자로만 표시하고 링크(<a href>)로 만들지 않았다.
  - http://www.w3.org/2000/svg 7개: SVG 그림의 표준 네임스페이스 식별자(통신 아님).
  - http://schemas.openxmlformats.org/... 1개: 엑셀(xlsx) 파일 구조를 읽기 위한 네임스페이스 식별자(통신 아님).

  [사용하는 브라우저 기능]
  - localStorage: 1곳. 구조방정식 화면에 입력한 "모형 문법 텍스트"만 저장해 다음에 다시 보여준다.
    분석 자료(데이터)는 저장하지 않는다. (src/app/app-3.js.txt 122, 135행)
  - document.execCommand('copy'): 사용자가 [복사] 버튼을 눌렀을 때 결과표를 클립보드에 넣는다.
  - URL.createObjectURL(Blob): 사용자가 [결과 저장]·[그림 저장]을 눌렀을 때 PC에 파일로 내려받게 한다.
  - FileReader: 사용자가 직접 고른 CSV/XLSX 파일만 읽는다.

  [자료의 흐름]
  사용자가 고른 파일 또는 붙여넣은 자료 → 브라우저 탭 메모리에서 계산 → 화면 표시.
  탭을 닫으면 자료는 사라진다. 외부 전송 경로는 없다.


4. 오픈소스·저작권 관련 고지 (검토 요청)
--------------------------------------
  외부 라이브러리를 포함하지 않으며, 코드는 이 프로젝트를 위해 새로 작성했다.
  다만 다음 부분은 기존 공개 코드나 알고리즘을 따랐으므로 검토자의 판단이 필요하다.

  (1) R 소스에서 이식한 부분 (R은 GPL-2 이상)
      - 스튜던트화 범위 분포 ptukey/wprob (Tukey, Games-Howell 사후검정용):
        R의 src/nmath/ptukey.c를 JavaScript로 거의 그대로 옮김
        (원 알고리즘: Copenhaver & Holland, 1988; Lund & Lund, 1983 AS 190).
      - Shapiro-Wilk 검정: R의 src/library/stats/src/swilk.c의 계수와 절차를 따름
        (원 알고리즘: Royston, 1995, Applied Statistics AS R94).
      ※ GPL의 의무(소스 공개 등)는 일반적으로 "배포"할 때 생긴다. 기관 내부에서만 사용하면 문제가 되지 않는
        경우가 많지만, 최종 판단은 기관 정책과 검토자에 따른다. 필요하면 이 두 부분을 논문 원문에 근거한
        독자 구현으로 바꾸거나, 해당 기능(Tukey·Games-Howell 사후검정, Shapiro-Wilk)을 빼고 쓸 수 있다.

  (2) 저자 공개 코드의 절차를 따른 부분
      - 이변량 정규분포 누적확률(bvnu): Alan Genz의 공개 알고리즘(Genz, 2004)을 따름.
        Genz 교수의 공개 코드는 BSD 유사 허가로 배포되는 것으로 알려져 있으나, 원문 고지 필요 여부는 확인 요망.

  (3) 논문이나 교과서의 표준 알고리즘을 참고해 새로 작성한 부분
      - 불완전 베타·감마 함수(연분수 전개, Lentz 방법), Lanczos 감마 근사, Acklam 정규분위수 근사,
        Brent 1차원 최적화, 그래피컬 라쏘(Friedman et al., 2008), 최근접 양정치 행렬(Higham, 2002),
        구조방정식 Fisher scoring 등.
      - 연분수 함수들은 Numerical Recipes에 소개된 표준 기법과 구조가 비슷하다. 코드를 복사하지는 않았다.

  (4) R 패키지와 결과를 맞춘 부분
      - qgraph, lavaan, psych 등과 "같은 결과"가 나오도록 계산 규칙을 맞췄다. 이 패키지들의 코드를 포함하지는
        않았다(동작 확인과 수치 대조에만 사용).

  이 프로젝트 자체에는 아직 라이선스 파일이 없다(개인 연구용).


5. 정확성 검증
-------------
  외부망 개발 환경에서 R 4.x(stats, car, psych, MASS, qgraph, glasso, lavaan 0.6-17)와
  Python(scipy, pingouin) 결과와 2,608개 수치를 자동 대조해 모두 일치했다(허용오차 내).
  검증 스크립트는 저장소 tests/ 폴더에 있다(이 묶음에는 포함하지 않음).


6. 반입 후 확인 방법
------------------
  - Windows 명령 프롬프트: certutil -hashfile PsyStat.html.txt SHA256
    → SHA256SUMS.txt의 값과 같아야 한다. 이름을 .html로 바꿔도 해시는 같다.
  - 브라우저에서 열었을 때 빨간 안내 상자("스크립트가 실행되지 않았습니다")가 보이면 스크립트가 차단된 것이다.
