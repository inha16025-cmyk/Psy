# FourPane: 4분할 파일 탐색기 (폐쇄망용)

Windows 10/11에 기본으로 들어 있는 PowerShell 5.1과 WinForms만 씁니다. 설치할 것도, 인터넷 연결도 필요 없습니다.

## 파일 구성
| 파일 | 용도 |
|---|---|
| `FourPane.ps1` | 프로그램 본체. **UTF-8(BOM)** 으로 저장해야 합니다. |
| `FourPane.bat` | 평소 실행용. 더블클릭하면 콘솔 창 없이 뜹니다. |
| `FourPane_debug.bat` | 문제가 생겼을 때 쓰는 실행 파일. 콘솔 창에 오류가 보입니다. |

세 파일을 **같은 폴더**에 두고 `FourPane.bat`을 더블클릭하세요.
**관리자 권한으로 실행하지 마세요.** 관리자 권한으로 실행하면 네트워크 드라이브 문자가 보이지 않을 수 있습니다.

## 텍스트로 옮겨 적을 때 (메모장 사용)
1. 메모장에 코드를 붙여넣습니다.
2. '다른 이름으로 저장'에서 **인코딩을 `UTF-8(BOM)`** 으로 고르고, 파일 이름을 `FourPane.ps1`로 저장합니다.
   그냥 `UTF-8`로 저장하면 한글 메뉴가 깨집니다.
3. `.bat` 파일 두 개는 영어로만 되어 있어서 인코딩을 신경 쓰지 않아도 됩니다.

## 기능
- **2×2 네 칸**: 경계선을 끌어 칸 크기를 바꿀 수 있습니다. `Ctrl+0`을 누르면 네 칸이 같은 크기로 돌아갑니다.
- **드라이브 ▼** 메뉴
  - 로컬, 이동식, **네트워크 드라이브**를 보여 줍니다.
  - 레지스트리(`HKCU\Network`)에 저장된 네트워크 드라이브는 이 창에서 드라이브 문자가 잡히지 않아도 `\\서버\공유` 경로로 바로 열립니다.
- **주소창**에 `D:\자료`, `\\서버\공유`, `%USERPROFILE%` 같은 경로를 직접 입력할 수 있습니다.
- **검색** (파일·폴더 이름 기준)
  - 띄어쓰기로 구분한 단어는 모두 들어간 이름만 찾습니다. 예: `녹취 2024`
  - 와일드카드를 쓸 수 있습니다. 예: `*.hwp`, `보고서_??.docx`
  - '하위 폴더 포함'을 체크하면 하위 폴더까지 찾고, '중지' 버튼으로 멈출 수 있습니다.
  - 결과는 최대 10,000개까지 보여 줍니다.
  - 결과 화면에서 오른쪽 클릭 → '이 항목이 있는 폴더로 이동'을 고르면 그 폴더가 열립니다.
- **끌어다 놓기**: 칸끼리, 그리고 Windows 탐색기와도 주고받을 수 있습니다. 기본은 **복사**이고, **Shift를 누른 채 놓으면 이동**합니다.
- **즐겨찾기 ★**, 열 머리글을 클릭해 정렬, 마우스 '뒤로' 버튼을 지원합니다.
- 창을 닫을 때 네 칸의 경로, 즐겨찾기, 창 크기를 `%APPDATA%\FourPane\settings.json`에 저장합니다.

## 단축키
| 키 | 동작 |
|---|---|
| Enter / 더블클릭 | 열기 |
| Backspace | 상위 폴더 |
| Alt+← | 뒤로 |
| F5 | 새로고침 |
| F2 | 이름 바꾸기 |
| Del | 삭제(휴지통으로). **네트워크 드라이브는 휴지통 없이 바로 삭제될 수 있습니다.** |
| Ctrl+C / Ctrl+V | 파일 복사 / 붙여넣기 |
| Ctrl+F / Ctrl+L | 검색창 / 주소창으로 이동 |
| Ctrl+1~4 | 1~4번 칸으로 이동 |
| Ctrl+0 | 네 칸을 같은 크기로 |

## 문제가 생겼을 때
- `FourPane_debug.bat`으로 실행하면 콘솔 창에 오류 메시지가 보입니다.
- 오류 기록은 `%APPDATA%\FourPane\error.log`에 남습니다.
- 회사 그룹 정책에서 스크립트 실행을 막아 두었다면 실행되지 않습니다. 이 경우 정책을 우회하지 말고 IT 부서에 문의하세요.
